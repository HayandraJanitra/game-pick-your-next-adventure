# 🎮 Game Pick

Game Pick adalah landing page modern untuk aplikasi rekomendasi game multi-platform yang membantu pengguna menemukan game terbaik berdasarkan perangkat yang digunakan, genre favorit, rating, dan popularitas game.

## 📖 Deskripsi Proyek

Website ini dibuat sebagai landing page untuk memperkenalkan aplikasi **Game Pick**, sebuah platform rekomendasi game yang mendukung berbagai perangkat seperti:

- Android
- iOS
- PC
- PlayStation
- Xbox
- Nintendo Switch
- Cloud Gaming

Landing page dirancang dengan tampilan modern bertema gaming menggunakan konsep dark mode, desain responsif, dan antarmuka yang mudah digunakan.

## 🚀 Cara Menjalankan Proyek

### 1. Clone Repository

```bash
git clone https://github.com/HayandraJanitra/game-pick-your-next-adventure.git
```

### 2. Masuk ke Folder Project

```bash
cd game-pick-your-next-adventure
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Development Server

```bash
npm run dev
```

### 5. Buka Browser

```text
http://localhost:5173
```
